BOBIN BABU — PORTFOLIO WEBSITE

Files:
- index.html: complete responsive portfolio website (CSS and JavaScript included)
- Bobin_Resume.pdf: copy your resume PDF here to enable the Download résumé button

HOW TO RUN
1. Extract the ZIP.
2. Put your resume PDF in the same folder as index.html and name it exactly: Bobin_Resume.pdf
3. Double-click index.html to preview in your browser.

CUSTOMIZE
- Edit index.html in VS Code.
- Update project descriptions or add links to live demos as you publish your projects.
- The project cards currently use email links because live project URLs were not provided.

PUBLISH
You can deploy this folder with GitHub Pages, Netlify, or another static hosting service.
